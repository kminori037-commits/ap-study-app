# AP Study App 要件定義書

## 1. 目的

応用情報技術者試験の科目A・科目Bを学習する、招待制のWebアプリを提供する。

## 2. 対象範囲

### 科目A

- 応用情報技術者試験の全分野
- 四肢択一問題

### 科目B

- 情報セキュリティ
- サービスマネジメント
- プロジェクトマネジメント
- 経営戦略
- システム監査
- データベース

## 3. ユーザーとアクセス制限

- Amazon Cognitoを利用する。
- 一般向けの自己登録は無効にする。
- 管理者がメールアドレスを指定して利用者を招待する。
- 一時パスワードはCognitoが自動生成し、利用者本人にだけ通知する。
- 利用者は初回ログイン時に一時パスワードを変更する。
- 本パスワードはCognitoだけがハッシュ化して保持し、管理者も取得できない。
- 未認証ユーザーは問題、正解、履歴、ブックマークへアクセスできない。
- URLを知っているだけでは学習機能を利用できない。
- 利用者本人が設定画面からアカウントを削除できる。
- アカウント削除時は再認証と二重確認を行い、履歴とブックマークも削除する。

## 4. 画面遷移

1. ログイン
2. 科目A／科目B選択
3. 一問一答／模擬テスト選択
4. 出題条件選択
5. 学習または受験
6. 結果表示
7. 履歴または復習

ログイン後のホーム画面には統計情報を表示せず、最初に科目A／科目Bを選択できるようにする。
科目Aと科目Bはそれぞれ独立して学習・受験・結果確認を行えるようにする。

## 5. 一問一答モード

- 科目と分野を選択できる。
- 全分野からの出題も選択できる。
- 科目Aはテクノロジ系、マネジメント系、ストラテジ系、および個別分野から選択できる。
- 科目Bは情報セキュリティ、サービスマネジメント、プロジェクトマネジメント、経営戦略、システム監査、データベースから選択できる。
- 問題をランダムに1問ずつ出題する。
- 同一セッション内では問題を重複させない。
- 出題対象を「すべて」「未回答」「過去に間違えた問題」「ブックマーク」から選択できる。
- 回答直後に採点結果、正解、詳細解説、出典を表示する。
- 好きな時点で終了できる。
- 1回のセッションは最大100問とする。
- 終了時に、その回の回答数、正解数、正答率、学習時間を表示・保存する。
- 累計正答率は計算・表示しない。
- 回答前後のどちらでもブックマークを追加・削除できる。

## 6. 模擬テストモード

### 科目A

- 試験時間は150分とする。
- 四肢択一問題を80問出題する。

### 科目B

- 150分とする。
- 情報セキュリティを必須とする。
- 残り5分野から4分野を選択し、合計5問へ回答する。

### 共通

- 科目Aだけ、または科目Bだけで模擬テストを開始・提出・終了できる。
- 科目Aと科目Bの受験セッション、結果、履歴は別々に保存する。
- 科目Aと科目Bを合算した正答率は表示しない。
- 回答中は進捗と残り時間を表示する。
- 回答状態と残り時間を保存し、途中離脱後に再開できる。
- 未完了テストがある場合は「続きから再開」「新しく開始」「キャンセル」を表示する。
- 「新しく開始」では確認後に以前の未完了テストを削除する。
- 時間切れの場合は自動提出する。
- 全問回答後または提出後に採点する。
- 結果画面に、その回の正解数、回答数、正答率、問題一覧を表示する。
- 累計正答率は計算・表示しない。
- 問題一覧から詳細な復習画面へ移動できる。

## 7. 採点

- 科目Aは自動採点する。
- 科目Bの数値・用語などの短答は、正規化と登録済み別解により自動採点する。
- 科目Bの説明記述は、模範解答と採点ポイントを表示し、利用者が「正解」「部分点」「不正解」を選択する。
- 科目Bの結果は、自動採点と自己採点を合算する。
- MVPではAI採点を使用しない。

## 8. 履歴と復習

- 学習1回ごとに日時、科目、モード、回答数、正解数、正答率、学習時間を保存する。
- 履歴画面では各回の正答率を表示する。
- 科目A・科目Bで履歴を絞り込める。
- 履歴詳細で問題別結果を確認できる。
- 間違えた問題だけを再出題できる。
- ブックマーク一覧から復習を開始できる。
- 履歴は本人だけが閲覧できる。
- 履歴は直近30日かつユーザーごとに最大50回まで保存する。
- 30日以内でも51回目の保存時に最も古い履歴を削除する。
- 期限切れ履歴はDynamoDB TTLで削除し、削除待ちの項目も画面に表示しない。
- 利用者は履歴をリセットできる。
- 履歴リセット時もブックマークは保持する。
- 問題ごとの最終回答状態とブックマークには保存期限を設けない。

## 9. 初回収録問題

- 2025年度春期の科目A問題
- 2025年度春期の科目B対象分野問題
- IPAの指定に従い、年度、期、試験区分、科目、問番号を出典として表示する。
- 解説は本アプリ独自の文章として作成する。

## 10. 問題データ管理

- 問題データは年度・期・科目別のJSONファイルでGitHub管理する。
- JSONスキーマによる形式チェックを自動化する。
- Pull Requestで確認されたデータだけをDynamoDBへ投入する。
- 正解データをフロントエンドの配信ファイルへ含めない。
- 問題管理画面はMVP対象外とする。

## 11. 対応環境

- 表示言語は日本語とする。
- PC、タブレット、スマートフォンへ対応する。
- 科目BはPC・タブレットを優先し、スマートフォンでも全機能を利用可能にする。
- 最新版のGoogle Chrome、Microsoft Edge、Safariを対象とする。
- ダークモードはMVP対象外とする。
- キーボードのみでも回答と画面移動を可能にする。
- 回答状態を色だけに依存せず、記号や枠線でも示す。

## 12. 技術構成

- フロントエンド: Next.js、TypeScript、Tailwind CSS
- ホスティング: AWS Amplify Hosting
- 認証: Amazon Cognito
- API: Amazon API Gateway HTTP API
- バックエンド: AWS Lambda
- データベース: Amazon DynamoDB
- 監視: Amazon CloudWatch
- インフラ管理: AWS CDK（TypeScript）
- バージョン管理: GitHub
- CI/CD: GitHub Actions、GitHub OIDC

## 13. 費用管理

- 有料サービスの作成前に無料枠と月額見積もりを提示し、利用者の承認を得る。
- 固定費の大きいNAT Gateway、RDS、OpenSearch、ElastiCache、常時稼働EC2、WAFはMVPで使用しない。
- ゼロ支出予算と月額5 USDの予算アラートを使用する。
