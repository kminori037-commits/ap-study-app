# AP Study App データ設計

## 1. 基本方針

- DynamoDBは問題用とユーザー学習用の2テーブル構成とする。
- Cognitoのユーザー固有IDをユーザーデータの境界として使用する。
- メールアドレスとパスワードはDynamoDBへ保存しない。
- 問題文を履歴へ複製せず、問題IDで参照する。
- 正解、解説、採点ポイントは回答または提出前にクライアントへ返さない。

## 2. QuestionBankテーブル

年度、期、科目をパーティションキー、問題番号をソートキーとして問題を格納する。

```text
PK: BANK#2025#SPRING#A
SK: QUESTION#001
```

正解情報は問題本文と別の項目に分離し、採点処理を行うLambdaだけが取得する。

```text
PK: BANK#2025#SPRING#A
SK: ANSWER#001
```

### 科目A問題

- 問題ID
- 年度、期、問番号
- 大分類、中分類
- 問題文
- 選択肢
- 図表参照
- 出典

### 科目A正解

- 正解選択肢
- 詳細解説

### 科目B大問

- 大問ID
- 年度、期、問番号、分野
- 共通問題文
- 図表参照
- 小問ID一覧
- 出典

### 科目B小問

- 小問ID
- 問題文
- 回答形式（短答または記述）
- 配点

### 科目B正解

- 模範解答
- 許容する別解
- 採点ポイントと点数
- 詳細解説

## 3. UserLearningテーブル

ユーザー固有IDをパーティションキーとし、項目種別をソートキーの先頭に付ける。

```text
PK: USER#<Cognito user sub>
```

| ソートキー | 用途 | 保存期限 |
| --- | --- | --- |
| `PROFILE` | 初回登録日時などの最小情報 | アカウント削除まで |
| `PROGRESS#<問題ID>` | 回答経験、最終結果、最終回答日時 | アカウント削除まで |
| `BOOKMARK#<問題ID>` | ブックマーク | アカウント削除まで |
| `SESSION#<完了日時>#<ID>#META` | 学習1回の概要 | 30日 |
| `SESSION#<完了日時>#<ID>#ANSWER#<問題ID>` | 問題別回答結果 | 30日 |
| `ACTIVE#A#QUIZ` | 科目Aの一問一答途中状態 | 完了・破棄まで |
| `ACTIVE#B#QUIZ` | 科目Bの一問一答途中状態 | 完了・破棄まで |
| `ACTIVE#A#MOCK` | 科目Aの模擬テスト途中状態 | 完了・破棄まで |
| `ACTIVE#B#MOCK` | 科目Bの模擬テスト途中状態 | 完了・破棄まで |

## 4. 履歴保持

- 一問一答は1セッション最大100問とする。
- 一問一答と模擬テストを合わせ、直近30日かつ最大50セッションを保持する。
- 51件目の完了時に最も古いセッション概要と回答詳細を削除する。
- 履歴項目には作成時から30日後のTTLを設定する。
- TTL期限後、物理削除前の項目もAPIで除外する。
- 未完了セッションは50件の履歴上限に含めない。
- 累計正答率は保存・計算しない。

## 5. 未完了テスト

科目・モードの組み合わせごとに未完了セッションを1件保持する。

未完了セッションがある状態で開始画面を開いた場合は次を表示する。

- 続きから再開
- 新しく開始
- キャンセル

「新しく開始」を選択した場合は確認画面を表示し、同意後に以前の未完了データを削除する。

## 6. 科目Bの採点

- 短答は正規化した回答と登録済み別解を比較して自動採点する。
- 記述は利用者が該当する採点ポイントを選択する。
- 正解は満点、不正解は0点とする。
- 部分点は選択した採点ポイントの合計とする。
- 科目Bの正答率は、獲得点を満点で割って算出する。

## 7. パスワード

- 招待時の一時パスワード生成と送信はCognitoに任せる。
- 管理者は一時パスワードを指定・記録しない。
- 本パスワードは利用者本人が設定する。
- アプリ、ログ、DynamoDB、GitHubへパスワードを保存しない。
- 管理者は現在のパスワードを取得できず、必要時は再設定手続きだけを行える。

## 8. アカウント削除

再認証と二重確認後に、次の順序で削除する。

1. ユーザー固有IDに属するUserLearning項目を削除する。
2. Cognitoユーザーを削除する。
3. ローカルの認証セッションを破棄する。

途中失敗時は処理を再実行できるよう、削除状態を管理する。

## 9. 概算容量

1回答を約2KB、一問一答の最大を100問、履歴上限を50回とすると、最大約10MB/ユーザーとなる。
10ユーザーでは約100MBに加えて問題データと索引が必要だが、DynamoDBの25GB無料ストレージ枠を十分に下回る見込みとする。
