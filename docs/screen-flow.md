# AP Study App 画面遷移設計

具体的な表示内容とレスポンシブ配置は、[画面レイアウト設計](./screen-design.md)を参照する。

## 1. 全体遷移

```text
ログイン
  ├─ 初回利用 → パスワード変更
  └─ ログイン済み
          ↓
ホーム（科目A／科目Bを選択）
          ↓
モード選択
  ├─ 一問一答
  │     ↓
  │   出題条件
  │     ↓
  │   問題 → 回答 → 採点・解説 → 次の問題
  │     ↓
  │   セッション終了
  │
  └─ 模擬テスト
        ↓
      テスト設定
        ├─ 科目A：80問・150分
        └─ 科目B：必須1分野＋選択4分野・150分
        ↓
      回答画面
        ↓
      提出確認
        ↓
      科目Bのみ：記述問題の自己採点
        ↓
      科目別結果
        ↓
      問題別の復習
```

## 2. 共通メニュー

認証後の画面から、次の機能へ移動できるようにする。

- ホーム
- 履歴
- ブックマーク
- 設定
- ログアウト

## 3. 画面一覧

| 画面 | 主な内容 |
| --- | --- |
| ログイン | メールアドレス、パスワード |
| 初回パスワード変更 | 招待時の一時パスワード変更 |
| ホーム | 科目A／科目Bの選択 |
| モード選択 | 一問一答／模擬テスト |
| 一問一答設定 | 分野、出題対象の選択 |
| 一問一答学習 | 問題、回答、採点、解説、ブックマーク |
| 模擬テスト設定 | 試験条件、科目Bの選択分野 |
| 模擬テスト回答 | 残り時間、進捗、問題移動、回答保存 |
| 提出確認 | 未回答数の警告、提出確定 |
| 科目B自己採点 | 模範解答、採点ポイント、自己採点 |
| 結果 | 受験した科目の正答率、問題一覧 |
| 履歴 | 各回の日時、科目、モード、正答率 |
| 履歴詳細 | 問題別の回答結果と復習 |
| ブックマーク | 保存した問題の一覧と再出題 |
| 設定 | パスワード変更、履歴リセット、アカウント削除 |

## 4. 一問一答の出題条件

### 科目A

- 全分野
- テクノロジ系
- マネジメント系
- ストラテジ系
- 個別分野

### 科目B

- 全分野
- 情報セキュリティ
- サービスマネジメント
- プロジェクトマネジメント
- 経営戦略
- システム監査
- データベース

各分野について「すべて」「未回答」「過去に間違えた問題」「ブックマーク」を指定できるようにする。

## 5. 科目別の模擬テスト

- 科目Aと科目Bは独立した模擬テストとする。
- どちらか一方だけで開始、提出、終了できる。
- 結果画面には受験した科目の結果だけを表示する。
- A・Bを連続して受験した場合も、別々の履歴として保存する。
- A・Bを合算した正答率は表示しない。
- 科目Bは自己採点の完了後に結果を確定する。

## 6. アクセス制御

- 未認証ユーザーはログイン画面以外へ移動できない。
- 問題、履歴、ブックマークは認証済み本人にだけ返す。
- 模擬テストの正解と解説は提出前に取得できない。
